Resume-To-Rank

Resume ranking for hiring teams

Upload resumes, parse candidate text, rank candidates by selected skills, sort results, and export a ranked CSV.

About the app

  • Flask backend with upload, parse, rank, sort, clear, and export endpoints.
  • Browser UI for uploading TXT, PDF, and DOCX resumes.
  • Skill criteria can be selected or added directly in the interface.

Hosting note

GitHub Pages hosts static files only. The live Flask API needs a Python hosting service such as Render, Railway, Fly.io, Azure App Service, or Heroku-compatible hosting.

Deployment-ready backend

The repository includes production hosting files: wsgi.py, Procfile, runtime.txt, and requirements.txt.

Use pip install -r requirements.txt as the build command and gunicorn wsgi:app as the start command on a Python host.
